# 레몬 짤 메이커 🍋

사용자가 제공한 이미지에서 왼쪽 남자가 제거된 레몬 배경 이미지를 사용하여, 다른 사진이나 캐릭터를 배치하는 **서버 없는 독립형 웹사이트**입니다.

이 버전에는 **브라우저 안에서 동작하는 자동 AI 누끼 기능**이 포함되어 있습니다.

## 사용법

1. ZIP 파일을 **압축 해제**합니다.
2. `index.html`을 Chrome, Edge, Safari 등에서 엽니다. `assets/lemon-background.png` 파일과 `index.html`을 함께 보관해야 합니다.
3. 왼쪽에 넣을 사진(PNG, JPG, WEBP 등)을 업로드합니다.
4. 기본값으로 **자동 AI 누끼**가 켜져 있으므로, 업로드 후 브라우저가 사람 배경 제거를 시도합니다.
5. 미리보기에서 드래그해 위치 이동, 마우스 휠이나 슬라이더로 확대·축소, 회전·반전할 수 있습니다.
6. 우측 레몬 보호 기능을 켜면 사진이 왼쪽 합성 영역을 넘지 않도록 자동으로 잘리고, 경계가 부드럽게 처리됩니다. 사진 전체를 표시하고 싶으면 보호 기능을 끄세요.
7. 문구를 추가할 수 있습니다. 문구 이동은 **글자 움직이기** 모드에서 가능합니다.
8. **완성 짤 PNG 다운로드**를 클릭하면 1254 × 1254 PNG가 저장됩니다.

## 자동 누끼 안내

- 사진 업로드 시 기본적으로 **자동으로 배경 제거**를 시도합니다.
- 첫 실행에서는 AI 모델을 내려받느라 **10~40초 정도** 걸릴 수 있습니다. 이후에는 브라우저 캐시에 저장되어 더 빨라질 수 있습니다.
- 처리 중 문제가 있으면 원본 사진은 그대로 유지됩니다.
- `원본 사진으로 되돌리기`, `누끼 결과 다시 사용`, `AI 누끼 다시 하기` 버튼으로 결과를 바꿀 수 있습니다.
- 이미지 처리는 브라우저 안에서만 수행되며 사진이 별도 서버로 업로드되지는 않습니다.

## 사진 합성 안내

- 배경이 제거된 **투명 PNG** 파일을 사용하면 사람/캐릭터가 배경과 가장 자연스럽게 합성됩니다.
- 일반 JPG도 사용할 수 있으며, 자동 누끼가 잘 되면 사람만 남길 수 있습니다.
- 이미지는 캔버스 밖으로 넘어가더라도 저장할 때 자동으로 캔버스 크기대로 잘립니다. 레몬 보호를 체크하면 레몬 근처의 오른쪽 영역도 자동으로 마스킹됩니다.

## GitHub Pages에 무료 배포

1. GitHub에서 공개 저장소를 만듭니다(예: `sample` 또는 `lemon-meme-maker`).
2. 저장소 루트에 `index.html`과 `assets/lemon-background.png`를 **같은 구조 그대로** 업로드합니다.
3. 저장소의 **Settings → Pages → Build and deployment**에서 `Deploy from a branch`, `main`, `/(root)`를 선택합니다.
4. 배포가 완료되면 `https://사용자명.github.io/저장소명/`에서 접속할 수 있습니다.

## 파일

- `index.html`: HTML/CSS/JS 포함한 단일 웹 앱
- `assets/lemon-background.png`: 사용자 요청에 맞게 남자가 제거된 레몬 배경 이미지
